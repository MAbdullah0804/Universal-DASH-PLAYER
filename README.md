# Universal-DASH-PLAYER
This is a front-end template for a DASH PLAYER. <br>

This player supports:<br>

MPEG-DASH (.mpd)<br>

HLS (.m3u8)<br>

Standard MP4 / WebM / MKV<br>

Local files from the user's device<br> <br>


This Project can be the starting point for a DRM-enabled secure streaming system.<br> <br>


We are working on adding features like:<br>

1. Upload videos<br>

2. Preview videos<br>

3. Annotate videos<br>

4.Submit review comments<br>

5.Share project files<br> <br>

Useful for video production teams.
